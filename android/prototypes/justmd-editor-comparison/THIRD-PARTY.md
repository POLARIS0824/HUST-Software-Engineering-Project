Material Symbols are from Google, under Apache License 2.0: https://github.com/google/material-design-icons/blob/master/LICENSE. The small vector icon set was reused from the first-round experiment.

CodeMirror packages are MIT licensed. The view package's original notice is packaged in `assets/licenses/CODEMIRROR-MIT.txt`; each installed package retains its own license in node_modules. Only the CM flavor bundles the editor JavaScript.

See https://github.com/mikepenz/multiplatform-markdown-renderer/blob/v0.39.2/LICENSE and the official AndroidX repositories for notices.
