# Selected disposable shape

Candidate A is the base. The independent gpt-6-sol judge and parent each gave both candidates 9/10. A explicitly includes the visible local editor sharing the same bundle with fidelity probes. B is smaller but omits that visible boundary.

Graft B's fixture validation, pinned asset verification, and retained structured failure observations. Keep native probes in functions rather than a generic runner framework. The visible session draft is never labelled saved. Native storage probes write only disposable files.

The implementation has a fixture/session file, a Compose shell, a local editor adapter with bundled HTML, and a native probe file. Native probes run separately from UI fixtures. A script prepares pinned assets and records their hashes. Small direct Compose state replaces StateFlow and a reducer because this isolated prototype has one activity and no concurrent state writers. This is a parent-accepted simplification of A's state holder, not a production architecture recommendation.

The requirements and design docs remain unchanged. The research report will distinguish observed results, upstream-source evidence, and unverified acceptance criteria.
